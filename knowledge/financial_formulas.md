# Financial formulas

## Annualized return

```text
annualized_return = (ending_value / beginning_value) ** (1 / years) - 1
```

## Net return after fee

Approximation:

```text
net_return = gross_return - annual_fee
```

## Break-even fee

The fee at which two strategies produce the same final net wealth.

Usually solved by sensitivity analysis rather than a closed-form formula.
